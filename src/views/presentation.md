# Presentation views

Overview places **Trabajos activos** first and emphasizes it over Cobrado hoy, Por cobrar and Consultas nuevas. The supplied statistics and callbacks remain unchanged. Quick actions retain their Spanish labels and distinguish Nueva reparación from secondary actions. Existing Ver detalle is supplied by `InlineOrder` within each work card.

Consultations group the existing name, telephone, problem, date, source and status by record. Finance keeps the fixed Hoy/Semana/Mes calculations, pending amount and both tables; Registrar gasto retains its callback. Parts remains read-only with the existing purchase records and quantities. Icons are decorative Lucide line icons.

For integration checks use visible labels: region **Indicadores**; buttons **Nueva reparación**, **Nuevo cliente**, **Registrar gasto**, **Ver trabajos →**, **Ver todos →**, **Ver detalle**; headings **Consultas comerciales**, **Movimientos y pendientes**, **Compras de repuestos**. Finance and parts tables retain the **Tabla desplazable horizontalmente** region label. SSR does not establish responsive layout or interactive behavior; check these in a browser.
